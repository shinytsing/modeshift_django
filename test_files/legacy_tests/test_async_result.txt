# 测试用例文档

## 模块1：购物车功能
### TC-001：添加商品到购物车
**测试场景**：用户将商品添加到购物车
**前置条件**：用户已登录，商品库存充足
**测试步骤**：
1. 用户打开购物车页面
2. 用户点击“添加商品”按钮
3. 选择商品并填写数量
4. 点击“确定”按钮
**预期结果**：商品成功添加到购物车，购物车中显示商品信息
**优先级**：P0
**测试类型**：功能

### TC-002：从购物车删除商品
**测试场景**：用户从购物车删除商品
**前置条件**：用户已登录，购物车中有商品
**测试步骤**：
1. 用户打开购物车页面
2. 点击商品旁边的“删除”按钮
3. 确认删除操作
**预期结果**：商品从购物车中移除，购物车显示更新后的商品列表
**优先级**：P0
**测试类型**：功能
