## 🚀 使用方法

### 快速启动
```bash
# 1. 安装依赖
pip3 install pytest pytest-django allure-pytest requests

# 2. 运行测试
python3 manage.py test tests.test_functional -v

# 3. 生成报告
allure generate tests/reports/allure-results -o tests/reports/allure-report --clean

# 4. 查看报告
open tests/reports/allure-report/index.html
```

### 一键执行
```bash
bash tests/run_full_test.sh
```
