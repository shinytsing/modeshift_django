## 🚀 应用简介

ClashX Pro 代理管理器是一个专为Mac用户设计的代理管理工具，可以方便地管理ClashX Pro代理的开启和关闭，支持配置文件管理、状态监控、连接测试等功能。

### 主要功能
- ✅ **一键代理开关** - 快速开启/关闭系统代理
- ✅ **实时状态监控** - 显示ClashX Pro运行状态和代理状态
- ✅ **配置文件管理** - 导入/导出/重置ClashX配置文件
- ✅ **连接测试** - 测试代理连接和获取当前IP
- ✅ **操作日志** - 记录所有操作和错误信息
- ✅ **管理界面** - 快速打开ClashX Pro管理界面

## 💻 系统要求

### 必需软件
- **macOS**: 10.13 或更高版本
- **Python**: 3.6 或更高版本
- **tkinter**: Python图形界面库（通常随Python一起安装）
- **ClashX Pro**: 代理客户端软件

### 推荐配置
- macOS 11.0+ (Big Sur或更高版本)
- Python 3.8+
- 8GB+ 内存
- 稳定的网络连接

## 📦 安装步骤

### 方法一：使用安装脚本（推荐）

1. **下载分发包**
   ```
   下载 ClashX代理管理器_分发包.zip
   ```

2. **解压文件**
   ```bash
   unzip ClashX代理管理器_分发包.zip
   cd ClashX代理管理器_分发包
   ```

3. **运行安装脚本**
   ```bash
   chmod +x install_clashx_manager.sh
   ./install_clashx_manager.sh
   ```

4. **启动应用**
   - 在Applications文件夹中找到"ClashX代理管理器"
   - 双击启动应用

### 方法二：手动安装

1. **检查Python环境**
   ```bash
   python3 --version
   python3 -c "import tkinter"
   ```

2. **安装ClashX Pro**
   - 从 [GitHub](https://github.com/yichengchen/clashX) 下载ClashX Pro
   - 拖拽到Applications文件夹

3. **复制应用文件**
   ```bash
   cp -R ClashX代理管理器.app /Applications/
   ```

## 📚 使用教程

### 首次使用设置

1. **启动应用**
   ```bash
   # 方法1: 双击应用图标
   # 方法2: 从Applications文件夹启动
   # 方法3: 使用Spotlight搜索启动
   ```

2. **检查ClashX Pro**
   - 确保ClashX Pro已安装并可以正常启动
   - 如果未安装，请先下载安装ClashX Pro

3. **导入配置文件**
   - 切换到"配置管理"选项卡
   - 点击"导入配置文件"
   - 选择您的ClashX配置文件（.yaml或.yml格式）
   - 等待导入完成

### 日常使用流程

#### 开启代理
1. 启动ClashX代理管理器
2. 检查ClashX Pro是否运行（如果未运行，点击"启动ClashX Pro"）
3. 点击"开启代理"按钮
4. 等待连接测试完成
5. 确认代理已成功开启

#### 关闭代理
1. 在状态监控页面点击"关闭代理"
2. 等待直连测试完成
3. 确认代理已成功关闭

#### 测试连接
1. 点击"测试连接"按钮
2. 查看连接测试结果
3. 检查当前IP地址是否正确

### 配置文件管理

#### 导入新配置
1. 切换到"配置管理"选项卡
2. 点击"导入配置文件"
3. 选择新的配置文件
4. 确认导入成功

#### 导出当前配置
1. 在配置管理页面点击"导出配置文件"
2. 选择保存位置和文件名
3. 确认导出成功

#### 重置配置
1. 点击"重置配置"按钮
2. 确认重置操作
3. 配置文件将被删除

## ❓ 常见问题

### Q1: 应用无法启动
**A**: 请检查以下项目：
- Python 3.6+ 是否已安装
- tkinter是否可用（运行 `python3 -c "import tkinter"`）
- 应用是否有执行权限

### Q2: ClashX Pro启动失败
**A**: 请检查：
- ClashX Pro是否正确安装在Applications文件夹
- 是否有足够的系统权限
- ClashX Pro版本是否兼容

### Q3: 代理开启失败
**A**: 可能的原因：
- ClashX Pro未运行
- 配置文件格式错误
- 网络接口名称不匹配（默认使用Wi-Fi）

### Q4: 连接测试失败
**A**: 检查项目：
- 代理服务器是否可用
- 网络连接是否正常
- 防火墙是否阻止连接

### Q5: 配置文件导入失败
**A**: 请确认：
- 文件格式为YAML
- 文件内容语法正确
- 文件路径没有特殊字符

### Q6: 权限不足
**A**: 解决方案：
- 使用管理员权限运行应用
- 在系统偏好设置中授予应用权限
- 检查系统代理设置权限

## 🔧 高级配置

### 自定义网络接口
如果您的网络接口不是"Wi-Fi"，可以修改代码中的接口名称：

```python
# 在enable_proxy和disable_proxy方法中
# 将 'Wi-Fi' 替换为您的网络接口名称
# 例如: 'Ethernet', 'USB 10/100/1000 LAN' 等
```

### 自定义代理端口
如果ClashX Pro使用不同的端口，可以修改以下配置：

```python
# HTTP代理端口 (默认7890)
"networksetup -setwebproxy 'Wi-Fi' 127.0.0.1 7890"

# SOCKS代理端口 (默认7891)  
"networksetup -setsocksfirewallproxy 'Wi-Fi' 127.0.0.1 7891"
```

### 自定义管理界面端口
如果ClashX Pro管理界面使用不同端口：

```python
# 在open_management方法中修改端口
success, stdout, stderr = self.run_command("open http://127.0.0.1:9090")
```
