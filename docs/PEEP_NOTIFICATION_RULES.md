# Peep 通知规则与回归要求

## 邮件规则

- 同一用户同一轮检查只发送一封汇总邮件。
- 汇总邮件按博主分组展示粉丝、关注、获赞/收藏和新内容变化。
- 新内容必须包含标题、可点击的小红书链接和对应封面图片；图片优先以内嵌 CID 发送，下载失败时保留 HTTPS 图片地址。
- 没有变化的关注对象也要在汇总中明确标记“本次没有更新”。
- 邮箱每日发送上限按收件邮箱计算，不按博主数量重复计算。

## 修改与验收规则

每次修改 Peep 功能必须同时检查已有能力，不能只修当前问题：

1. 运行 `python3 -m py_compile` 检查所有改动的 Python 文件。
2. 运行 `DJANGO_SETTINGS_MODULE=config.settings.development python3 manage.py check`。
3. 回归验证订阅、取消关注、快照对比、粉丝/关注变化、新内容、站内提醒和汇总邮件。
4. 邮件回归必须确认 HTML 中仍有图片、标题和跳转链接；不能因为改成汇总而丢失图片。
5. 改动后重启 Django，再访问 `/tools/peep/` 做一次 HTTP 检查。
6. 只有实际验证通过后，才能报告功能完成。
